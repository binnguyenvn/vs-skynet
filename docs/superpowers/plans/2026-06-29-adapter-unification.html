Goal

Pull codex/claude/agy behind one AgentAdapter interface emitting a normalized WorkerEvent stream, and collapse the three byte-identical classify.ts copies and three near-identical webview bridges into one each. Pure refactor — spawn/JSONL/cancel mechanics unchanged.

Implement task-by-task via superpowers:subagent-driven-development or executing-plans. Each task ends green (npm test) and is committed.

Global Constraints

  • Decision A holds — no fallback/retry; pure refactor, no behavior change.
  • Shared RunOpts = common fields (prompt, cwd, model?, configDir?, oauthToken?); advanced knobs in <Cli>RunOpts extends RunOpts (sidesteps the sandbox string-vs-boolean conflict).
  • Usage mapping: codex cached_input + claude cache_read → cachedInputTokens; claude cache_creation → cacheWriteTokens; codex reasoning_output → reasoningTokens; claude total_cost_usd → costUsd.
  • Mocha suite/test + node:assert; npm test runs the suite. Real-CLI suites gated by CODEX_E2E/CLAUDE_E2E.
  • Commits end with the Co-Authored-By: Claude Opus 4.8 trailer.
