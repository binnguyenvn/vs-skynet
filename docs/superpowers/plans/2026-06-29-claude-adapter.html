Claude Code (claude) Adapter — Implementation Plan

2026-06-29 · spec: 2026-06-29-claude-adapter-design.md · mirrors codex adapter

Phase 1 — MVP 5 tasks · 2 user stories TDD · frequent commits

Goal

A standalone, concrete TypeScript adapter that runs a task through the Claude Code CLI (claude -p --output-format stream-json) and turns its JSONL output into a typed, observable event stream with a clear terminal status, plus a manual webview smoke UI to prove it. New code lives in src/adapters/claude/, mirroring src/adapters/codex/ and src/adapters/agy/.

Global constraints

  • Verified: claude 2.1.195. Invocation: claude -p "<prompt>" --output-format stream-json --verbose [--model m] --permission-mode <mode> [--allowedTools …] --add-dir <cwd>.
  • --verbose required for the full event stream under -p. Prompt is positional, right after -p (before the variadic flags). stdin 'ignore'; cwd via spawn option + --add-dir.
  • Permission default 'default' — tools denied (no approver under -p), the safe read-only-equivalent. Opt in to tool work via permissionMode / allowedTools.
  • Tests in src/test/, run with npm test. Real-CLI test gated behind CLAUDE_E2E.
GOTCHA — success ≠ subtype. Success requires exitCode === 0 AND a result event with is_error === false. An observed run returned subtype:"success" with is_error:true ("Not logged in"). Gate on is_error, never subtype.
3rd classifyError consumer. Copied verbatim from codex; classifies on result.result text AND stderr (claude reports failures in the structured result field). Strongest trigger yet to extract a shared classifier — but that extraction stays its own US.

US-1: Claude Code adapter

A working, tested runClaude(opts) that streams typed events and resolves a terminal ClaudeResult. Proven via fake-CLI fast tests + a gated real-CLI test. No UI required.
