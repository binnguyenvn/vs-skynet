Goal

A standalone TypeScript adapter that runs a task through agy --print and turns its plain-text output into a typed, observable event stream with a clear terminal status, plus a manual webview smoke UI.

Architecture

Mirror src/adapters/codex/ in a new src/adapters/agy/: events.ts, classify.ts (copied verbatim from codex), agy-adapter.ts (runAgy), webview-bridge.ts. --print emits plain text only, so the event type carries the full target shape (started/thought/tool_call/usage) but only message is populated today; the rest are forward-compat stubs for a future Python-SDK sidecar.

Global Constraints

  • Verified agy 1.0.13: agy --print [--dangerously-skip-permissions] [--sandbox] [--model <m>] --add-dir <cwd> "<prompt>". Plain markdown on stdout, exit 0 on success. No --json/usage/threadId/events.
  • --dangerously-skip-permissions mandatory headless; --sandbox restricts FS. Both default on.
  • No -C flag → set child cwd via spawn + pass --add-dir <cwd>. stdin 'ignore'.
  • No shared types; classifyError copied verbatim from codex (extraction trigger noted, not done here).
  • Success = clean exit (0); usage always undefined today.
  • Tests in src/test/, run with npm test; real-CLI test gated behind AGY_E2E.
