Adapter Unification — Design

2026-06-29 · Epic: Adapters (subsystem 1) · Features: Normalized WorkerEvent stream + Error classification

Parent: skynet-vision adapters--events adapters--errors Phase 1 — MVP

Goal

The three adapters (codex, claude, agy) were each built concrete-first and are now structurally identical: a runX() returning an AsyncIterable<XEvent> plus cancel() and result: Promise<XResult>, a per-CLI events.ts, and a classify.ts that is a byte-for-byte copy across all three. The adapter specs deliberately deferred the shared types; the ponytail comments in the code name the extraction trigger explicitly.

This is that extraction. Pull all three adapters behind one AgentAdapter interface emitting one normalized WorkerEvent stream, and collapse the three identical classifiers into one classifyError — the end state the vision spec's Phase-1 row already describes.

Still in scope of Decision A: adapters stay dumb bridges. No fallback/retry, no step-function panel, no orchestrator. Pure refactor — same spawn, JSONL, and cancel mechanics; only the emitted shape is normalized and the classifier is deduped.

Current state

src/adapters/
  codex/  { events.ts (CodexEvent/CodexUsage/CodexResult), classify.ts, codex-adapter.ts, webview-bridge.ts }
  claude/ { events.ts (ClaudeEvent/ClaudeUsage/ClaudeResult), classify.ts, claude-adapter.ts, webview-bridge.ts }
  agy/    { events.ts (AgyEvent/AgyUsage/AgyResult), classify.ts, agy-adapter.ts, webview-bridge.ts }
  • The three classify.ts are identical; ErrorClass is declared three times.
  • XResult is identical across all three.
  • Event unions overlap but diverge in field names; usage shapes differ per provider.
  • Each <cli>/webview-bridge.ts is a near-identical streamXTestToWebview, differing only by log channel and per-CLI fields.

The normalized contract — src/adapters/types.ts

export type ErrorClass = "limit" | "transport" | "terminal";

export type WorkerEvent =
  | { kind: "started"; sessionId: string; model?: string }  // codex/agy threadId → sessionId; model claude-only
  | { kind: "message"; text: string }
  | { kind: "thinking"; text: string }                      // agy "thought" folds in here
  | { kind: "tool_call"; name: string; input: unknown }     // agy "args" → input
  | ({ kind: "usage" } & WorkerUsage)
  | { kind: "unknown"; raw: unknown };

export interface WorkerUsage {
  inputTokens: number;
  outputTokens: number;
  cachedInputTokens?: number;  // codex cached_input + claude cache_read (both cache reads)
  cacheWriteTokens?: number;   // claude cache_creation
  reasoningTokens?: number;    // codex reasoning_output
  costUsd?: number;            // claude only
}

export interface WorkerResult {
  status: "success" | "failed" | "cancelled";
  reason?: string; errorClass?: ErrorClass;
  usage?: WorkerUsage; lastMessage?: string;
}

export interface RunOpts {     // the COMMON contract; adapters widen it
  prompt: string; cwd: string; model?: string;
  configDir?: string;          // CODEX_HOME / CLAUDE_CONFIG_DIR / HOME
  oauthToken?: string;         // claude-only; other adapters ignore it
}
// Advanced knobs stay per-adapter (sandbox is a string union in codex but a
// boolean in agy — can't share one field):
//   CodexRunOpts  extends RunOpts { sandbox?: "read-only" | "workspace-write" | "danger-full-access" }
//   ClaudeRunOpts extends RunOpts { permissionMode?; allowedTools? }
//   AgyRunOpts    extends RunOpts { sandbox?: boolean; skipPermissions? }

export interface WorkerRun extends AsyncIterable<WorkerEvent> {
  cancel(): void;
  result: Promise<WorkerResult>;
}

export interface AgentAdapter {
  readonly id: "codex" | "claude" | "agy";
  run(opts: RunOpts): WorkerRun;
}

Shared classifier — src/adapters/classify.ts

The single copy of the existing function (unchanged behavior; same LIMIT/TRANSPORT regexes). Call sites unchanged: codex/agy classify stderr on non-zero exit; claude classifies the result text (a 429 in the result still → limit). Only the function is shared.

Adapter & bridge changes

  • Each <cli>/events.ts: mapXLine returns normalized WorkerEvent(s); per-CLI types deleted.
  • Each <cli>/<cli>-adapter.ts: imports shared classify/types; exports an AgentAdapter value ({ id, run }). runX internals unchanged.
  • New src/adapters/webview-bridge.ts: generic streamAdapterTestToWebview(adapter, webview, cwd, overrides) + one formatEvent. Posts { type: `${adapter.id}Log` } — narrows to the existing protocol union, so protocol.ts is unchanged. The three <cli>/webview-bridge.ts deleted.
  • panel.ts: each testX selects the matching adapter and calls the one bridge. The three buttons/log panels stay (developer smoke UI).

Data flow

panel → streamAdapterTestToWebview(adapter) → adapter.run(opts): WorkerRun
      → yields WorkerEvent → formatEvent → { type: `${id}Log` } postMessage
      → run.result: WorkerResult → "done success" / "done <status>: <reason>"

Testing

  • *-events.test.ts rewritten to assert normalized WorkerEvent/WorkerUsage (claude: cachedInputTokens+cacheWriteTokens+costUsd; codex: cachedInputTokens+reasoningTokens; agy thought→thinking; started.model only for claude).
  • One shared classify.test.ts replaces the three identical copies.
  • *-adapter.integration.test.ts updated to shared types; CODEX_E2E/CLAUDE_E2E real-CLI proofs stay green.
  • One webview-bridge.test.ts asserts the generic bridge over a fake AgentAdapter, incl. the posted type matching adapter.id.
  • npm test (pretest compiles + lints) stays green.

User Stories

  • US-1 — Normalized adapter core (adapters--events + adapters--errors): shared types.ts + classify.ts; all three adapters emit WorkerEvent, expose an AgentAdapter, call the shared classifier; per-CLI types and the three classifiers deleted.
  • US-2 — Generic webview bridge: one webview-bridge.ts over WorkerEvent; three <cli>/webview-bridge.ts deleted; panel.ts rewired; bridge tests collapsed. protocol.ts and React UI unchanged.

Out of scope (YAGNI)

  • New event fields (meta/timestamps/sequence), a tool_result kind, or streaming partial text — no CLI feeds them today.
  • Backfilling started.model for codex/agy (stays optional).
  • Fallback/retry/AgentPool (Decision A — later Orchestrator concern).
  • Replacing the smoke UI with a real observability panel (subsystem 2).
  • Refining classifier regexes against real limit/transport output (data-driven follow-up).
