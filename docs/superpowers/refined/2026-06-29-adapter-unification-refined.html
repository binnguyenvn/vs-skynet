Adapter Unification — Refined User Stories

2026-06-29 · Spec + Plan: 2026-06-29-adapter-unification-*

2 vertical slices adapters--events adapters--errors
Audit found no slicing violations. US-1 folds the shared types into the same feature that consumes them (not a standalone "types" layer); US-2 is the downstream consumer collapse. The two roadmap slugs live in US-1 together because deduping the classifier and switching to the normalized event stream touch the same adapter files — one refactor, not two features.

US-1: Normalized adapter core — all three CLIs speak one event language

What it does: codex, claude, and agy each emit their own slightly different event objects and each ship an identical copy of the error classifier. This makes them emit one shared event shape (WorkerEvent) and result, expose a common AgentAdapter handle, and call one shared classifier — so the app (and the future orchestrator) can drive any CLI without knowing which one it is.

Scope — In
  • Shared types.ts + classify.ts.
  • All three events.ts mappers return WorkerEvent(s).
  • All three adapters use shared types and export <id>Adapter: AgentAdapter.
  • Per-CLI event/usage/result types + three classify.ts copies deleted; tests rewritten (incl. gated real-CLI proofs).
Scope — Out
  • Bridge collapse (US-2); new event fields; fallback/retry (Decision A); classifier regex refinement.
Acceptance
  • Normalized events: started.sessionId (model claude-only); agy thought→thinking, args→input; usage carries cachedInputTokens/cacheWriteTokens/reasoningTokens/costUsd as applicable.
  • Each adapter exports an AgentAdapter returning a WorkerRun.
  • One shared classifyError; no per-CLI event types or classifiers remain.
  • npm test green incl. gated real-CLI runs.
Tasks

Task 1 (shared types + classifier), Task 2 (codex), Task 3 (claude), Task 4 (agy).

US-2: Generic webview bridge — one smoke-test path for every adapter

What it does: the three near-identical "Test X" bridges become one generic bridge taking any AgentAdapter. A developer still clicks Test Codex / Test Claude / Test Agy and watches the run stream — one code path instead of three.

Scope — In
  • New src/adapters/webview-bridge.ts (streamAdapterTestToWebview + unified formatEvent).
  • Delete three <cli>/webview-bridge.ts + three tests; one new generic test.
  • Rewire panel.ts to pick the adapter per test message.
Scope — Out
  • protocol.ts + React UI unchanged; no production observability panel.
Acceptance
  • Posts Starting <Id> test..., one line per event, then done success/done <status>: <reason> on the ${adapter.id}Log channel.
  • started without model omits the parenthetical; usage shows only present fields.
  • Old bridges/tests gone; npm test green; each button streams to its panel ending in done success.
Tasks

Task 5 (generic bridge + panel rewire).
